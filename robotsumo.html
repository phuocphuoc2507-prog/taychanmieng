Sàn Đấu Code Sumo

Mỗi người nạp code tối ưu của mình vào xe (vẽ theo đúng mẫu CAD của nhóm), lưu lại, rồi cho đấu. Sân đen viền trắng — ra ngoài là thua.

Cùng phần cứng — chỉ khác CODE. Ai tối ưu giỏi hơn thì thắng.

Cách nạp code của bạn

1. Gõ tên vào ô tên · 2. Viết/sửa hàm dauSi(s) trong ô code · 3. Bấm 💾 Lưu → chiến thuật của bạn vào thư viện (nhớ trên máy này) · 4. Ai cũng chọn lại từ ô "Đã lưu" để đấu.

Hàm dauSi(s) chạy ~30 lần/giây: nhận s (cảm biến), trả [trái, phải] = công suất 2 motor (−1..1). [1,1] tiến · [1,-1] xoay phải · [-1,-1] lùi.
